- **Entry and clean-up beside each booking** (Requests, Approved, Schedule): "In from <start - EarlyEntryMinutes> · Booked <start>–<end> · Clean-up until <end + CleanupMinutes>" from the facility row, in America/New_York. - **Setup > Facility rules** edits `EarlyEntryMinutes`, `CleanupMinutes`, `CheckoutAlertMinutes` (plus the existing limits and the two check-in alert timings, which are not early entry) and the **Approve automatically when everything is free** toggle (`AutoApproveWhenFree`, default off, hint "Needs client confirmation: the client approves every booking by hand"). The column is being added to the list by another change; until it exists the toggle's formulas error.
- **Adjust departure** (Approved): same-day Eastern HH:MM plus a required reason; writes `AvenueBookings.ActualEndUtc` and appends the reason to `OverlapNote`.
- **Book (Screen9)** uses the same availability rule as Requests (`conflicts()` in `gen.py`), blocking Book with a reason text.

| Availability rule | Member portal (`availability.ts`) | Staff app (Requests, Book) |
|---|---|---|
| What blocks | Approved bookings only (pending never block) | Approved bookings only |
| Unit match | Unit id in the entry's equipment ids; a whole-facility booking blocks every unit | Unit id shared with the booking's `EquipmentIds`; a whole-facility booking is listed as an overlap but does not block Approve or Book (unchanged behaviour; owner decision pending) |
| Overlap | start < other end and end > other start (touching is free) | Same |
| Early entry and clean-up windows | Not part of the blocking interval | Shown beside the booking, not part of the blocking interval |
| Reason text | "Taken until <time>" | "<unit> is booked by <name> until <time>" |
| Source of data | Calendar entries | `AvenueBookings` (approved) and `AvenueCalendar` for the display name |
