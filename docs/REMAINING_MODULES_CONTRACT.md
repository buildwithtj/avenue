## Pattern (same as every module)
Members write only to **own-items intake lists** (item-level, author = identity). A Power Automate flow copies the item to a **private case list** that staff read, and echoes display-only text (`Outcome`, `Reply`) back to the member's own item. The UI is never a security boundary. Flows are only *specified* in `flows/expressions.md` (new section "Specified, not built"), never created.

## Lists (all have `FacilityId` Text indexed first; names exact)
Intake (access `intake`, `itemLevel: true`; own items only):
- **AvenueSupportMessages**: MessageId (Text, indexed, unique), ThreadId (Text, indexed; equals the first MessageId of a conversation), Category (Choice: Booking, Billing, Documents, Equipment, Other), Subject (Text), Body (Note), Outcome (Text, display only), Reply (Note, display only).
- **AvenueEventRequests**: RequestId (Text, indexed, unique), Package (Choice: Simplicity, Opulence, Elevation, Platinum), EventDate (DateTime), Guests (Number), Notes (Note), Outcome (Text), Reply (Note).

Private (access `private`, staff Contribute):
- **AvenueSupportCases**: CaseId (unique), ThreadId (indexed), MemberId (indexed), Category (Choice as above), Subject, LastMessage (Note), Status (Choice: Open, Answered, Closed), StaffReply (Note), RepliedBy, RepliedAt (DateTime), CreatedAt (DateTime).
