A little guide

Explore, then read

All 12 main phases sit on one horizontal line. All 57 stages are already visible above or below their phase; nothing is collapsed. Scroll to move left/right, drag to pan, and use the zoom controls or pinch. Overview fits the whole workflow; Readable view restores a usable scale. A ↳ marker identifies exception/child stages; their original parent is available in details. Select a node for its explanation and technologies.

Colors carry meaning

Each phase has a branch color. A blue left edge means a client email change; purple means the manager’s interface proposal; an amber right edge means an unresolved decision. Green marks your additions. Color labels are also written in the detail panel.

Customize

Select a phase to add a stage there. Select any stage to add before, after or as a child, edit it, reorder siblings, delete or lock it. New stages are Custom by default. The latest client changes remain attached to existing stages when edited.

Saving and finalizing

Browser autosave keeps edits in this browser where supported. It is not cloud sync. Save HTML downloads a portable self-contained copy with the current content embedded. Use Backup/Import for JSON. On phones those options and Lock map are available by selecting the central Avenue node. A locked stage or map has no unlock button; keep an editable backup first. Locks prevent edits through this interface, not external HTML file modification.

What this contains

All four original Phase 1 documents reconciled with the ten email screenshots and later chat clarifications. Original nine modules are retained. Later email decisions override conflicts: Stripe replaces QuickBooks, member SharePoint web parts replace member Power Apps, paid onboarding precedes document upload, conflict-free bookings auto-confirm, owner-only eligibility overrides apply, and B Street analytics are separated from the Flavors operational dashboard.

Confirmed = stated requirement; Needs decision = unresolved rule or implementation; Proposed implementation = recommendation; Future = Phase 2; Custom = your addition. There are 57 original stages, with email comparisons attached to 38 affected stages. Screenshot numbers refer to the supplied order, not individual email dates.
