Security model: member-scoped lists (Bookings is shared-read; Payments, Compliance, Checklists stay private) use SharePoint item-level permissions. The sync account creates Payments rows, so each member is granted item-level read via a reusable child flow. Filtering in the app runs on the plain-text MemberEmail column so it stays delegable.
